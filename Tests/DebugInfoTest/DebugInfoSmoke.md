# DebugInfoSmoke
## Description
`-g`/`--debug` DWARF emission smoke test: compiling with debug info must not change program behavior. Exercises every debug-metadata shape — free functions, recursion, a class with fields + methods (value-class `this` with readable `this.x`/`this.y` in gdb), locals, and string building — and asserts byte-identical stdout with and without the flag. The DWARF itself (DISubprogram source-level names so `break fib` works in gdb, per-function DIFile attribution with directory, DILocalVariable/DIExpression records) is generated by `LLVMEmitter.debug_*` behind `debug_enabled`; this test guards that enabling it never breaks codegen on any compiler. gdb-level acceptance (breakpoints resolve to .penguin files/lines, args/locals/fields printable) was verified manually with `readelf --debug-dump=info` + gdb against all Apply-To compilers; a known gdb quirk is honored: DISubprogram must NOT carry `linkageName`, or gdb's cooked index drops the natural name and `break fib` fails (mangled ELF symbols stay reachable via the ELF symtab).

## Apply To
* BabyPenguin
* EmperorPenguin Pass1
* EmperorPenguin Pass2
* EmperorPenguin Pass3

## Test Code
```
class Point {
    x: mut i64 = 0;
    y: mut i64 = 0;

    fun new(mut this, x: i64, y: i64) {
        this.x = x;
        this.y = y;
    }

    fun magnitude_squared(this) -> i64 {
        return this.x * this.x + this.y * this.y;
    }
}

fun add(a: i64, b: i64) -> i64 {
    let sum: i64 = a + b;
    return sum;
}

fun fib(n: i64) -> i64 {
    if (n <= 1) {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}

initial {
    let a: i64 = 10;
    let b: i64 = 32;
    let total: i64 = add(a, b);
    println("total = " + cast<string>(total));

    let p: mut Point = new Point(3, 4);
    let m: i64 = p.magnitude_squared();
    println("magnitude_squared = " + cast<string>(m));

    let f: i64 = fib(10);
    println("fib(10) = " + cast<string>(f));
}
```
